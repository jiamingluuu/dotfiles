# 飞书前置

本 BABI 指南仅复用已有的 `lark-cli` 飞书能力；保持该命令形式，也不要安装、升级或配置该 CLI。
执行表格校验或回写前，加载环境中可用的飞书 Skill，并按它自己的认证、授权和写入安全流程操作。

只有命令明确返回认证或权限错误时才进入登录或增量授权流程；不要预先读取、打印或持久化 token。

### 飞书资源的用户权限边界

预算查询、CD 映射和填报表格操作必须使用**当前发起请求用户**授权的飞书身份。确认
CLI 的用户身份与本次请求用户一致，并在资源调用中显式传 `--as user`；`auto`、
`--as bot` 或共享账号不能替代这项检查。已有应用配置或 bot 可访问不代表用户有权限，
用户令牌有效也不代表其可访问目标文档。

缺少该用户授权、无法确认身份归属，或目标资源返回权限拒绝时，停止读取该资源，说明
需要用户授权或由文档所有者授予访问权限。不得切换 bot、共享身份、其他用户账号，
也不得使用这些身份取得的缓存或导出内容生成派生结果；不得自动扩大文档共享范围。
仅继续不依赖受限资源、且当前用户已有权限的任务部分。
